Ferramentas com intenção.

Dois apps desenvolvidos pela organização AIOS, ambos abertos, ambos escritos para viver dentro do mesmo runtime local do aios.

01 · AGENT INFRASTRUCTURE

Laya Gateway

Em construção · MIT · open source App próprio

Um gateway local que pergunta à Laya — uma especialista minúscula que só responde perguntas tipadas como “qual ferramenta?” ou “sim/não?”, com score de confiança — qual ferramenta o agente deve chamar. Se ela não souber, a requisição segue intacta para o seu modelo habitual. O agente ganha roteamento sem transformar toda decisão em uma chamada cara.

Web SQLite Admin

Sistema e terceiros

O que está por trás dos apps.

Os apps próprios conversam com duas coisas: o runtime do sistema, feito de crates próprios em Rust, e utilitários de terceiros que o aios adota como componente.

Sistema · aioscrates próprios, mesmo repositório

É o que faz parte do sistema operacional: o daemon, os CLIs, o núcleo de modelos e o SDK. Todo o código é do projeto aios.

Sistema

edge-ai

Daemon HTTP local com API JSON, inferência, benchmark, logs, métricas e painel web num binário só.

~8 MB crate edge-ai
Sistema

edge & ai

edge para status, models, run, benchmark, logs, monitor e serve. ai para install, run, doctor e ai task (summarize, classify, intent, translate, qa).

edge status · ai task crate aios-cli
Sistema

ai-core & ai-inference

Parser GGUF com streaming, SHA-256, cache e registry TSV, com backend de inferência Candle CPU por baixo.

aios-core · aios-inference ai-core ai-inference
Sistema

edge-sdk

SDK dos apps de borda: carrega um modelo do registry e gera tokens com métricas de TPS e tempo de load.

generate_with_metrics crate aios-sdk
Apps de terceirosprojetos externos adotados pelo aios

Não são desenvolvidos pela organização e não são apps do AIOS: são projetos abertos de terceiros, executados no mesmo runtime local e creditados como tal.

Terceiros

ai-memory

Memória de longo prazo para os agentes do sistema, em binário único Rust, sem chave de API no caminho padrão.

MIT · akitaonrails projeto
Terceiros

ai-jail & ai-usagebar

Sandbox de sistema operacional para os agentes e a barra de cota dos provedores, ambos em Rust por akitaonrails.

GPL-3.0 · MIT · akitaonrails ai-jail ai-usagebar
